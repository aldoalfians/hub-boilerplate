# Internationalization (i18n)

## Stack

- `i18next` — core engine
- `react-i18next` — React bindings (`useTranslation`, `Suspense`)
- `i18next-http-backend` — lazy load locale files from `/public/locales/`

## Supported Languages

| Code | Language |
|------|----------|
| `id` | Indonesian (default) |
| `en` | English |

Add more in `src/lib/i18n.ts` → `SUPPORTED_LANGS`.

## File Structure

```
public/locales/
├── id/
│   └── common.json     ← Indonesian translations
└── en/
    └── common.json     ← English translations
```

Adding namespace: create `public/locales/{{lang}}/dashboard.json` per language, then add `'dashboard'` to `ns` in `src/lib/i18n.ts`.

## `useI18n` Hook

Primary hook for all components:

```tsx
import { useI18n } from '@/hooks';

const MyComponent = () => {
  const { t, lang, setLang, isLoading } = useI18n();

  return <h1>{t('home.title')}</h1>;
};
```

With specific namespace:
```tsx
const { t } = useI18n('dashboard');
t('welcome')  // loads from public/locales/{{lang}}/dashboard.json
```

## `t()` Usage Patterns

```tsx
// Simple key
t('common.save')                          // → "Simpan" | "Save"

// Nested key
t('auth.login.title')                     // → "Masuk" | "Login"

// Interpolation
t('validation.required', { field: 'Email' })  // → "Email wajib diisi"
t('table.total', { count: 100 })              // → "Total 100 data"
```

## Using `t` Outside React (static)

```ts
import { t } from 'i18next';

// Works outside components — note: NOT reactive to lang change
const label = t('common.save');
```

## Language Switching

```tsx
const { lang, setLang } = useI18n();

setLang('en');   // persisted to localStorage, syncs i18next + antd locale
setLang('id');
```

Language is persisted via `useLanguageStore` (Zustand → `hub-lang` in localStorage).
Ant Design locale (`idID` / `enUS`) auto-switches in `ConfigProvider` (see `main.tsx`).

## Adding a New Language

1. Add code to `SUPPORTED_LANGS` in `src/lib/i18n.ts`
2. Create `public/locales/{{code}}/common.json`
3. Import antd locale and add to `antdLocaleMap` in `src/main.tsx`
4. Add menu item in `AppLayout.tsx` langMenuItems

## Adding a New Namespace

1. Create `public/locales/id/dashboard.json` and `public/locales/en/dashboard.json`
2. Add `'dashboard'` to `ns` array in `src/lib/i18n.ts`
3. Add to `SupportedNs` type in `src/lib/i18n.ts`
4. Use: `const { t } = useI18n('dashboard')`

## Locale File Convention

Use dot-notation keys grouped by domain:

```json
{
  "auth": {
    "login": {
      "title": "Masuk",
      "subtitle": "Masukkan kredensial Anda"
    }
  },
  "common": {
    "save": "Simpan",
    "cancel": "Batal"
  }
}
```

Avoid flat keys — nested grouping prevents collisions and is easier to maintain.
